# Milestones M0–M18

- **M0–M6:** foundation, demo services, telemetry, incident persistence,
  Alertmanager intake, and verified-only Hindsight memory.
- **M7:** safe Prometheus, Loki, Tempo, incident-context, and memory evidence tools.
- **M8:** allowlisted deployment history and checked-in runbook retrieval.
- **M9:** typed evidence, hypothesis, diagnosis, and tool-call contracts.
- **M10:** bounded provider-driven investigation with Groq and a test FakeProvider.
- **M11:** persisted approval/rejection and idempotent simulated actions.
- **M12:** current-telemetry recovery verification before resolution.
- **M13:** human root-cause verification, postmortem review, and memory commit.
- **M14:** operator UI for scenarios, incidents, evidence, timeline, and approvals.
- **M15:** reproducible checkout, payment, and healthy-baseline scenarios.
- **M16:** deterministic evaluation with machine- and human-readable results.
- **M17:** request and rate limits, redaction, allowlists, and fail-closed behavior.
- **M18:** deployment configuration, operational documentation, and validation.

The model never approves or directly executes a mitigation.
